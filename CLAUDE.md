This repo is the **Liquid Glass Kit** (iOS 27 Liquid Glass for React / Next.js).

Before changing anything, or before using this kit to restyle another site, read
**[packages/glass-kit/LIQUID-GLASS-GUIDE.md](packages/glass-kit/LIQUID-GLASS-GUIDE.md)** —
rules, component catalog, presets, and the step-by-step upgrade procedure.

- Kit source: `packages/glass-kit/src` (public API in `src/index.ts`)
- Demo site: `apps/docs` (`npm run dev` from the repo root)
